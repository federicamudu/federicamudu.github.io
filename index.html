Les Apèritifs

Sito per aperitivi

Linguaggi usati: HTML, CSS, JavaScript

Lingua supportata: Italiano

Tipologia: Progetto personale

Les Apèritifs è un piccolo progetto realizzato utilizzando solamente tecnologie di Frontend. Si può tranquillamente ampliare con la struttura di un Backend e la possibilità di essere aggiornato. I drink al suo interno sono salvati su un file json che, in questo caso, fa da piccolo database. All'interno del sito possiamo trovare anche la funzionalita di ricerca per parola, prezzo e difficoltà.

Potteraniesimo

Sito web a tema Harry Potter

Linguaggi usati: HTML, CSS, JavaScript

Backend: PHP, API, Laravel

Lingua supportata: Italiano

Tipologia: Progetto personale, Progetto extra Hackademy154

Il progetto potterianesimo è un sito web basato sulla serie di film Harry Potter. Il sito contiene una navbar, nella quale sono collegate le pagine dei personaggi, dei libri, degli incatesimi e infine una pagina con un form di contatto. È presente anche la pagina di dettaglio sia per i personaggi che per i libri, comprensiva di immagine e di descrizione. Il sito è interamente responsive.

Soundstorm

Sito web per amanti della musica

Linguaggi usati: HTML, CSS, Bootstrap

Backend: PHP, Laravel, MySQL

Lingua supportata: Italiano

Tipologia: Progetto personale

Il progetto Soundstorm è un sito web per amanti della musica, dove possono trovare pubblicare e ascoltare i loro brani preferiti. All'interno potremo caricare una traccia musicale da parte di un utente loggato al sistema, avremo una visualizzazione pubblica delle tracce pubblicate dagli utenti. Saranno presenti due ruoli principali: utente e amministratore. Quest'ultimo potrà creare nuovi generi musicali. Il sito è completo di funzionalità CRUD, ossia creazione, aggiornamento, cancellazione e lettura.
