MotoGP Hub

API in Python & Frontend in React

Backend: Python (REST API), Vercel

Frontend: React

Tipologia: Architettura Disaccoppiata

Un ecosistema diviso in due repository distinte per separare nettamente la logica backend dall'interfaccia utente. Il backend, sviluppato in Python e deployato su Vercel, si occupa di esporre API RESTful per fornire dati complessi (in sola lettura). Il frontend (MotoGP Hub), sviluppato in React, consuma questi endpoint per mostrare dinamicamente agli utenti le informazioni sul prossimo Gran Premio, le classifiche aggiornate e i dettagli dei piloti.

F1 Mission Control

Web App di Telemetria & AI

Stack: Python, Streamlit

API: OpenF1 (Live), Ergast (Storico), Google Gemini (AI)

Tipologia: Data Processing & Integrazione AI

Un hub strategico interattivo per la Formula 1, costruito interamente in Python. Il cuore backend del progetto elabora enormi moli di dati richiamando API esterne: fonde la telemetria live dei transponder ufficiali (OpenF1) con dati storici e classifiche (Ergast). I dati grezzi vengono ripuliti e manipolati tramite Pandas per generare dashboard in tempo reale. Il progetto integra inoltre Google Gemini per dare vita all'"Ingegnere di PistAI": un assistente conversazionale capace di leggere di nascosto il JSON dei dati live per rispondere a domande tattiche sulla gara in corso.
*Nota: L'app è ospitata sul cloud gratuito di Streamlit. Se all'apertura dovesse comparire il messaggio "This app has gone to sleep", clicca semplicemente su "Yes, get this app back up!" per risvegliarla in pochi secondi.

Soundstorm

Piattaforma Streaming Audio

Backend: PHP, Laravel, MySQL

Frontend: HTML, CSS, Bootstrap

Tipologia: Applicazione Full-Stack

Soundstorm è una piattaforma web completa, sviluppata su architettura MVC con Laravel. Ho curato la progettazione del database relazionale (MySQL), l'implementazione del sistema di autenticazione e l'assegnazione dei ruoli (utente base e amministratore). Il backend gestisce le funzionalità CRUD per il caricamento, la modifica e l'eliminazione delle tracce musicali e la creazione dinamica di nuovi generi da parte degli admin.
